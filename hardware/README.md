# 🛠️ Smart Pillbox Hardware Specification

스마트 약통 하드웨어의 모듈 구성 및 회로 연결 사양입니다. 본 기기는 ESP32-C3 메인 컨트롤러를 중심으로 복약 감지 센서 및 알림 모듈이 유기적으로 통합되어 작동합니다.

## 2. 주요 부품 명세 (BOM - Bill of Materials)
| 부품명 | 역할 및 기능 | 비고 |
| :--- | :--- | :--- |
| **ESP32-C3 Mini** | 메인 MCU (Wi-Fi/BLE 통신 및 전체 센서 제어) | 핵심 컨트롤러 |
| **적외선 장애물 감지 센서** | 약통 칸별 약품 존재 및 탈착 여부 실시간 감지 | 복약 판단 센서 |
| **액티브 부저 (Buzzer)** | 복약 시간 알림을 위한 사운드 경보 발생 | 청각 알림 |
| **LED 모듈 (Red/Green)** | 현재 기기 상태 및 복약 대상 칸 위치 시각적 안내 | 시각 알림 |
| **TP4056 충전 모듈** | 리튬 이온 배터리 충전 및 전력 안정화 관리 | 전원 관리 |
